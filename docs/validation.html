  • ありでは、修復期の順位が筆者と同じになります。

3. 既知の限界

型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。

ベンチマークの観察は代理で、一文ごとの読みとシグナルを含みません。partisanship と embodiment は、ベンチマーク上では効いていません。

観察の規則と定数の一部は、検証データを見ながら調整しました。一致度は甘めに出ています。

作例の結果は規則の向きの確認であり、人間の評定で検証したものではありません。

ショックの表出の規則（E-10）は仮説です。

4. 次に行う検証

  1. 人間のブラインド評定を集める：blind.py でシミュレータとの差を測る（手順は 人間評定）。作例の組（23問）と、ベンチマークから抜いた40問程度から始める。
  2. 層Aを独立に観察する：observe で観察し、同じ検証をやり直す。
  3. 型の比率と幅を推定する：20〜30人程度の評定で推定する。筆者を含む各評定者が母集団に収まるかを見て、収まらなければ軸を足す。
  4. ヒステリシスを識別する：経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作る。
  5. シグナルの規則を確かめる：作例の組に人間の評定を付け、向きと大きさを確かめる。
