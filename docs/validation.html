規則の向きは同じ

4値モデル（2.3.3）と同じ向きです。笑いと「てへっ」は、現実のタスクで重く（失礼 55）、物語の軽い失敗で軽く（32）なります（D-011）。

ファジィで見えるようになったもの

重すぎるのに足りない（S1 土下座：足りない 51・重すぎる 38）。失礼かつ足りない（S2 バツが悪そう：失礼 49・足りない 79）。半々（S5 修正だけ：足りない 50・釣り合う 50）。4値の先勝ちでは、どれも一つの評定に吸収されていました。

平均と裾は別のこと

現実のタスクの「てへっ」は、平均所属度 55 で、失礼と感じる人 100%。この減点は受け手の性質にほとんど左右されないので、全員が「やや失礼」の少し上に並び、0.5 で切る割合が跳ねます。物語の「へらっと笑う」は平均 50 でも 26% です。主には平均所属度を見ます。

失礼の所属度関数の中心は、最初に置いた 1.5 では作例のどの回答でも失礼と感じる人が 0% になったため、1.2 に下げました。1.2 は、単独で最大級の失点（相手への指摘 1.2）で所属度が 0.5 になる位置です（P4）。旧版で失礼の判定に効いていた不足量を失点から切り離した影響で、作例を見た後の調整です。

修復期の論理の欠陥。謝罪を受け入れた後、詫びを繰り返さない正しい回答でも、必要な中身との差を「不足」として数えます。サブエージェント観察では、修復期の一致が 0.33（代理観察 0.79）に落ちました。v0.7 では閾値の下に隠れていました。

評価指標「近さ」の欠陥。正解が4値のとき、最頻の評定を断定的に出すほど得をします。「常に釣り合う」が近さで最良（0.820）になりました。二乗誤差（Brier）では、シミュレータ 0.536 < 常に釣り合う 0.719 < ペルソナ 0.84〜0.91 と、まともな順位になります。

LLM の観察では厳しすぎる。回答の観察が「失礼」を（24 → 40）、場面の観察が不満の深さを通じて「足りない」を（25 → 35）押し上げます。失礼の中心の最適値は観察者で変わり（代理 1.0〜1.2、サブエージェント 1.5）、観察者ごとの較正が必要です。

3. 既知の限界

型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。

ベンチマークの観察は代理で、一文ごとの読みとシグナルを含みません。partisanship と embodiment は、ベンチマーク上では効いていません。

観察の規則と定数の一部は、検証データを見ながら調整しました。一致度は甘めに出ています。

作例の結果は規則の向きの確認であり、人間の評定で検証したものではありません。

ショックの表出の規則（E-10）は仮説です。

所属度関数の中心となだらかさ、「釣り合う」の t ノルム（min）は事前値です。失礼の中心は作例を見て調整しました（2.1）。

LLM の観察を通すとシミュレータが厳しすぎ、修復期の論理と評価指標「近さ」に欠陥があります（2.2、総合評価）。

4. 次に行う検証

  1. 人間のブラインド評定を集める：blind.py で、4つの述語×5段階の評定を集め、シミュレータとの差を測る（手順は 人間評定）。作例の組（23問）と、ベンチマークから抜いた40問程度から始める。あわせて、「釣り合う」の t ノルム（min か積か）と、所属度関数の中心・なだらかさを推定する。
  2. 修復期の論理と評価指標を直し、所属度関数を観察者ごとに較正する（総合評価 12章）。
  3. 層Aを独立に観察する：observe で観察し、同じ検証をやり直す。
  4. 型の比率と幅を推定する：20〜30人程度の評定で推定する。筆者を含む各評定者が母集団に収まるかを見て、収まらなければ軸を足す。
  5. ヒステリシスを識別する：経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作る。
  6. シグナルの規則を確かめる：作例の組に人間の評定を付け、向きと大きさを確かめる。
