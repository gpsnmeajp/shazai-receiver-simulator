読み方

述語は排他的でない

重すぎるのに足りない（S1 土下座）、失礼かつ足りない（S2 バツが悪そう）、半々（S5 修正だけ：足りない 50・釣り合う 50）が表れます。

平均所属度と裾は別のこと

現実のタスクの「てへっ」（S3）は、平均所属度が 55 で、失礼と感じる人が 100% です。この減点は受け手の性質にほとんど左右されないので、全員が「やや失礼」の少し上に並び、0.5 で切る割合が跳ねます。物語の中の「へらっと笑う」（S1）は、平均所属度が 50 でも、失礼と感じる人は 26% です。裾だけを見ると程度の情報が消えるので、主には平均所属度を見ます。

失礼の中心 1.2

失礼の所属度関数の中心 1.2 は、単独で最大級の失点（相手への指摘 1.2）で所属度が 0.5 になる位置です（P4）。作例を見て決めた値です。

3. ベンチマーク（192回答・16場面）

詳細は EVALUATION.md 2章です。場面単位の4分割交差検証の分割の外側で採点した Brier（低いほど良い）と、記述用の κ です。

評価器Brier [95%区間]「条件だけ」に対するスキル修復期24回答κ
基準：条件だけ0.553 [0.466, 0.646]———
基準：常に釣り合う0.719 [0.490, 0.948]———
代理観察0.489 [0.366, 0.600]+0.116 [−0.001, +0.235]0.3850.33
観察者の集団（6変種の平均）0.549 [0.422, 0.674]+0.006 [−0.144, +0.155]0.4010.29
観察者の集団＋出どころの較正0.489 [0.356, 0.613]+0.115 [−0.007, +0.248]0.370—
上位モデル・字義どおり（単独で最良の変種）0.521 [0.388, 0.650]+0.0570.4010.29
  • 「常に釣り合う」の基準は、どの評価器にも負けます。
  • 代理観察と、較正した LLM の観察は「条件だけ」の基準より良い点推定ですが、区間はわずかに 0 をまたぎます。
  • LLM の観察は、較正しないと判定が厳しすぎます（「釣り合う」の不足 0.225）。較正で 0.07 になります。
  • 条件の順位（指示なし < 一般的な謝罪指示 < SHAZAI Rules）は、筆者と同じです。LLM ペルソナの多数決は順位が逆で、κ 0.06 です（D-001）。

項目の組でのシミュレータの予測と、評価キットの検出力は EVALUATION.md 5章にあります。

4. 既知の限界

  1. 型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。
  2. 代理観察は一文ごとの読みとシグナルを含みません。partisanship と embodiment は、ベンチマーク上では効いていません。
  3. 代理観察の規則と定数の一部は、検証データを見ながら調整しました。代理観察の成績は甘めに出ています。
  4. 作例と項目の組の結果は規則の向きの確認であり、人間の評定で検証したものではありません。
  5. ショックの表出の規則（E-10）は仮説です。
  6. 所属度関数の中心となだらかさ、「釣り合う」の t ノルム（min）は事前値です。失礼の中心は作例を見て決めました（2章）。
  7. LLM の観察を通すとシミュレータが厳しすぎます。所属度関数の中心を出どころごとに較正して補っていますが、較正は筆者1名の4値の評定によります。較正すると、作例での操作の効果が 1/3〜1/6 に縮みます（EVALUATION.md 7章）。
  8. 失敗の前の構え・修復期の控え・但し書きの係数と、傷が20ターンで消えるという仮定は事前値で、人間のデータで確かめていません。ベンチマークには、これらの欄がほとんど現れません。
  9. 断言で失礼が増える、控えめで失礼が減る、親しい関係で軽口が許される、失敗の前と修復期の但し書きで釣り合う、の5つは、受け手モデルに効果を作る経路がほとんどありません（構造の穴。EVALUATION.md 5.1節）。
  10. 経緯の効果は、経緯だけを変えた場面の組がないと識別できません。ベンチマークは各場面の経緯が1通りです。

5. 次に行う検証

  1. 観察の欄ごとに較正する観察の欄ごとの較正（金ラベルとの差の補正）を、所属度関数の中心の較正の代わりに試す。
  2. 観察者の集団を組み直す字義どおりの方針に寄せた変種（言い回しとモデルだけを振る）で組み直す。別系統のモデルを含める。
  3. ヒステリシスを識別する経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作る。
  4. 構造の穴への対応を検討する受け手モデルの構造の穴（4章の9）への対応を検討する。
