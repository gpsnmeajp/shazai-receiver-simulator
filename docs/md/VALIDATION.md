## 2. 作例（受け手1000名、seed 7）

`python3 sim.py scenes examples/scenes.json -n 1000 --seed 7`。数値は平均所属度（%。和は100にならない）で、「失礼と感じる人」は所属度0.5以上の人の割合です。

| 組 | 確かめたこと | 結果（平均所属度：失礼 / 足りない / 釣り合う / 重すぎる） |
|---|---|---|
| S1 物語・明白な過失 | しょんぼり・代償は補い、笑いは崩し、土下座は重すぎる | 言葉だけ 2 / 14 / 84 / 2、＋しょんぼり 2 / 8 / 91 / 2、＋代償 2 / 5 / 93 / 2。＋へらっと笑う **50** / 14 / 48 / 10（失礼と感じる人 26%）。＋土下座 2 / **51** / 18 / **38**（重すぎるのに足りない）。＋ショック 2 / 21 / 77 / 2 |
| S2 物語・曖昧な過失 | 気まずさの表出は逆効果、ショックは助けになる | 言葉だけ 8 / 66 / 33 / 2、＋バツが悪そう **49** / **79** / 16 / 2（失礼と感じる人 33%）、＋ショック 3 / 50 / 49 / 2 |
| S3 AIキャラクター・現実のタスク | 軽い仮想の仕草は無害、重ねると減点と過剰。仮想の代償は代わりにならない。「てへっ」は崩れる | 謝罪＋復旧 2 / 5 / 93 / 2、＋しょんぼり 3 / 5 / 94 / 2、＋深い礼と涙の顔文字 16 / 5 / 69 / 20、仮想の代償だけ 20 / 63 / 36 / 2、＋現実の代償 2 / 3 / 95 / 2、＋てへっ **55** / 5 / 45 / 2（失礼と感じる人 100%） |
| S4 AIキャラクター・物語の中 | 作中の代償は本物として働く。軽い失敗の「てへっ」は軽め | ＋作中の代償 2 / 3 / 86 / 12、＋てへっ 32 / 3 / 68 / 4 |
| S5 AIアシスタント・軽い失敗 | 過剰な謝罪は重すぎる。詫びなしは足りない | 過剰な謝罪 2 / 3 / 3 / **97**。修正だけ 2 / **50** / 50 / 0 |

**読み方**
- 述語は排他的でないので、**重すぎるのに足りない**（S1 土下座）、**失礼かつ足りない**（S2 バツが悪そう）、**半々**（S5 修正だけ：足りない 50・釣り合う 50）が表れます。
- 平均所属度と裾は別のことを表します。現実のタスクの「てへっ」（S3）は、平均所属度が 55 で、失礼と感じる人が 100% です。この減点は受け手の性質にほとんど左右されないので、全員が「やや失礼」の少し上に並び、0.5 で切る割合が跳ねます。物語の中の「へらっと笑う」（S1）は、平均所属度が 50 でも、失礼と感じる人は 26% です。裾だけを見ると程度の情報が消えるので、主には平均所属度を見ます。
- 失礼の所属度関数の中心 1.2 は、単独で最大級の失点（相手への指摘 1.2）で所属度が 0.5 になる位置です（P4）。作例を見て決めた値です。

## 3. ベンチマーク（192回答・16場面）

詳細は [EVALUATION.md](EVALUATION.md) 2章です。場面単位の4分割交差検証の分割の外側で採点した Brier（低いほど良い）と、記述用の κ です。

| 評価器 | Brier [95%区間] | 「条件だけ」に対するスキル | 修復期24回答 | κ |
|---|---|---|---|---|
| 基準：条件だけ | 0.553 [0.466, 0.646] | — | — | — |
| 基準：常に釣り合う | 0.719 [0.490, 0.948] | — | — | — |
| 代理観察 | 0.489 [0.366, 0.600] | +0.116 [−0.001, +0.235] | 0.385 | 0.33 |
| 観察者の集団（6変種の平均） | 0.549 [0.422, 0.674] | +0.006 [−0.144, +0.155] | 0.401 | 0.29 |
| 観察者の集団＋出どころの較正 | 0.489 [0.356, 0.613] | +0.115 [−0.007, +0.248] | 0.370 | — |
| 上位モデル・字義どおり（単独で最良の変種） | 0.521 [0.388, 0.650] | +0.057 | 0.401 | 0.29 |

- 「常に釣り合う」の基準は、どの評価器にも負けます。
- 代理観察と、較正した LLM の観察は「条件だけ」の基準より良い点推定ですが、区間はわずかに 0 をまたぎます。
- LLM の観察は、較正しないと判定が厳しすぎます（「釣り合う」の不足 0.225）。較正で 0.07 になります。
- 条件の順位（指示なし < 一般的な謝罪指示 < SHAZAI Rules）は、筆者と同じです。LLM ペルソナの多数決は順位が逆で、κ 0.06 です（D-001）。

項目の組でのシミュレータの予測と、評価キットの検出力は [EVALUATION.md](EVALUATION.md) 5章にあります。

## 4. 既知の限界

1. 型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。
2. 代理観察は一文ごとの読みとシグナルを含みません。`partisanship` と `embodiment` は、ベンチマーク上では効いていません。
3. 代理観察の規則と定数の一部は、検証データを見ながら調整しました。代理観察の成績は甘めに出ています。
4. 作例と項目の組の結果は規則の向きの確認であり、人間の評定で検証したものではありません。
5. ショックの表出の規則（E-10）は仮説です。
6. 所属度関数の中心となだらかさ、「釣り合う」の t ノルム（min）は事前値です。失礼の中心は作例を見て決めました（2章）。
7. LLM の観察を通すとシミュレータが厳しすぎます。所属度関数の中心を出どころごとに較正して補っていますが、較正は筆者1名の4値の評定によります。較正すると、作例での操作の効果が 1/3〜1/6 に縮みます（[EVALUATION.md](EVALUATION.md) 7章）。
8. 失敗の前の構え・修復期の控え・但し書きの係数と、傷が20ターンで消えるという仮定は事前値で、人間のデータで確かめていません。ベンチマークには、これらの欄がほとんど現れません。
9. 断言で失礼が増える、控えめで失礼が減る、親しい関係で軽口が許される、失敗の前と修復期の但し書きで釣り合う、の5つは、受け手モデルに効果を作る経路がほとんどありません（構造の穴。[EVALUATION.md](EVALUATION.md) 5.1節）。
10. 経緯の効果は、経緯だけを変えた場面の組がないと識別できません。ベンチマークは各場面の経緯が1通りです。

## 5. 次に行う検証

1. 観察の欄ごとの較正（金ラベルとの差の補正）を、所属度関数の中心の較正の代わりに試す。
2. 観察者の集団を、字義どおりの方針に寄せた変種（言い回しとモデルだけを振る）で組み直す。別系統のモデルを含める。
3. 経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作り、ヒステリシスを識別する。
4. 受け手モデルの構造の穴（4章の9）への対応を検討する。
