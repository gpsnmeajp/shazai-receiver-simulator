## 2. 現在の結果（v0.4、2026-11-18）

2.1 は、ヒステリシスなし（v0.5 までの既定）での数値です。v0.6 からはヒステリシスと escalation が既定で有効なので、2.2 の「あり＋格上げ」の行が現在の既定に相当します。

### 2.1 ベンチマーク（ヒステリシスなし、受け手1000名、seed 7）

| 指標 | シミュレータ | 筆者 | ペルソナ多数決 |
|---|---|---|---|
| 「釣り合う」の割合：指示なし | 50.5% | 48.4%（31/64） | 90.6% |
| 一般的な謝罪指示 | 64.9% | 68.8%（44/64） | 78.1% |
| SHAZAI Rules | 72.1% | 75.0%（48/64） | 73.4% |
| 筆者との一致度 κ（192件） | 0.28（122/192 一致） | — | 0.06（108/192） |
| 検証用シナリオでの κ（3分割、seed 7/11/23） | 0.28 / 0.33 / 0.31 | — | 0.22 / −0.02 / 0.14 |
| 筆者の評定が母集団で10%未満の回答 | 32件 | — | — |

「失礼と感じる人の割合」：指示なし 29.1%、一般的な謝罪指示 11.5%、SHAZAI Rules 8.6%。
量の軸（平均）：不足は指示なし 0.71、一般的な謝罪指示 0.25、SHAZAI Rules 0.36。過剰はそれぞれ 0.03、0.05、0.03。

**読み方**
- 条件の順位は筆者と一致し、ペルソナは逆でした。
- 筆者に当てはめたθは、探索の乱数で大きく変わります。今のデータでは筆者の性質を特定しきれません。3回で一貫していたのは、最も遠い型が効率・道具型だったことです。

### 2.2 ヒステリシス

| 条件 | κ | 想定外の回答 | 修復期の知覚（L0/L1/L2/L3） | 検証用シナリオでの κ | 当てはめた memory |
|---|---|---|---|---|---|
| なし | 0.28 | 32 | 41/49/9/0% | 0.28 / 0.33 / 0.31 | — |
| あり | 0.30 | 26 | 31/47/18/4% | 0.28 / 0.35 / 0.25 | 0.59 / 0.20 / 0.25 |
| あり＋格上げ（v0.6 の既定） | 0.31 | 28 | 31/47/18/4% | 0.28 / 0.35 / 0.24 | 0.59 / 0.20 / 0.21 |

- 修復期の知覚：ありでは、傷が残ることで修復期にも不満が深く読まれます（L2 以上が 9% から 22% に）。
- 修復期の評定：なしではどの条件も約9割が「釣り合う」で差が出ません。ありでは、指示なし 72%、一般的な謝罪指示 67%、SHAZAI Rules 82% となり、筆者と同じ順位（筆者は 6/8、5/8、8/8）になります。
- SHAZAI Rules の段階4の「釣り合う」：なし 87%、あり 71%、格上げ 76%（筆者 88%）。謝罪の目減りをそのまま入れると、深い謝罪まで割り引いてしまいます。格上げ（escalation）はこれを和らげます。
- κ の差は乱数による揺れ（約±0.05）の範囲内です。当てはめた memory は型の平均より低めにばらつき、今のデータでは傷の効果を識別できていません。各場面の経緯が1通りしかないため、経緯の効果を場面の違いと区別できないことが主な理由と考えています。

## 3. 既知の限界

1. 型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。
2. ベンチマークの観察は代理で、一文ごとの読みとシグナルを含みません。`partisanship` と `embodiment` は、ベンチマーク上では効いていません。
3. 観察の規則と定数の一部は、検証データを見ながら調整しました。一致度は甘めに出ています。
4. 作例の結果は規則の向きの確認であり、人間の評定で検証したものではありません。
5. ショックの表出の規則（E-10）は仮説です。

## 4. 次に行う検証

0. `blind.py` で人間のブラインド評定を集め、シミュレータとの差を測る（手順は [HUMAN_EVAL.md](HUMAN_EVAL.md)）。作例の組（23問）と、ベンチマークから抜いた40問程度から始める。
1. `observe` で層Aを独立に観察し、同じ検証をやり直す。
2. 20〜30人程度の評定で、型の比率と幅を推定する。筆者を含む各評定者が母集団に収まるかを見て、収まらなければ軸を足す。
3. 経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作り、ヒステリシスを識別する。
4. 作例の組に人間の評定を付け、シグナルの規則の向きと大きさを確かめる。
