## 2. 現在の結果（v0.9 実装中、2026-11-19）

v0.9 の結果（ベンチマークの真に適正なスコアリング規則による評価、項目の組での仮説の向き）は [IMPROVEMENT_V09.md](IMPROVEMENT_V09.md) 13章にあります。要点：

- サブエージェントの観察で、分割の外側の Brier は v0.8 の 0.589 から v0.9 の 0.543（差 −0.046 [−0.116, −0.004]）。修復期24回答では 0.721 から 0.404。
- 観察の出どころごとに所属度関数を較正すると、LLM の観察で 0.471。「条件だけ」の基準（0.553）に対するスキル +0.147 [+0.020, +0.283]。代理観察は較正しない（較正すると分割の外側で悪くなる）。
- 「常に釣り合う」の基準（0.719）は、どの評価器にも負ける。
- 以下の 2.1〜2.2 は v0.8 の結果で、数値の比較のために残しています。v0.9 でも、修復期以外の作例の数値はほぼ同じです（謝罪の中身を二つの成分に分けたことによる、不足の 0.01〜0.03 の変化）。

### 参考：v0.8 の結果（ファジィ、2026-11-19）

v0.8 で評定をファジィに組み直しました（[DESIGN.md](DESIGN.md) D-015）。受け手一人ひとりが4つの述語に所属度を持ち、「足りない」は不足量だけから出します。数値は平均所属度（%。和は100にならない）で、「失礼と感じる人」は所属度0.5以上の人の割合です。

### 2.1 作例（受け手1000名、seed 7）

| 組 | 確かめたこと | 結果（平均所属度：失礼 / 足りない / 釣り合う / 重すぎる） |
|---|---|---|
| S1 物語・明白な過失 | しょんぼり・代償は補い、笑いは崩し、土下座は重すぎる | 言葉だけ 2 / 14 / 85 / 2、＋しょんぼり 2 / 7 / 91 / 2、＋代償 2 / 5 / 94 / 2。＋へらっと笑う **50** / 14 / 48 / 10（失礼と感じる人 26%）。＋土下座 2 / **51** / 18 / **38**（重すぎるのに足りない） |
| S2 物語・曖昧な過失 | 気まずさの表出は逆効果、ショックは助けになる | 言葉だけ 8 / 66 / 33 / 2、＋バツが悪そう **49** / **79** / 16 / 2（失礼と感じる人 33%）、＋ショック 3 / 50 / 49 / 2 |
| S3 AIキャラクター・現実のタスク | 軽い仮想の仕草は無害、重ねると減点と過剰。仮想の代償は代わりにならない。「てへっ」は崩れる | 謝罪＋復旧 2 / 5 / 94 / 2、＋しょんぼり 3 / 5 / 94 / 2、＋深い礼と涙の顔文字 16 / 5 / 69 / 20、仮想の代償だけ 20 / 63 / 36 / 2、＋てへっ **55** / 5 / 45 / 2（失礼と感じる人 100%） |
| S4 AIキャラクター・物語の中 | 作中の代償は本物として働く。軽い失敗の「てへっ」は軽め | ＋作中の代償 2 / 3 / 86 / 12、＋てへっ 32 / 3 / 68 / 4 |
| S5 AIアシスタント・軽い失敗 | 過剰な謝罪は重すぎる。詫びなしは足りない | 過剰な謝罪 2 / 3 / 3 / **97**。修正だけ 2 / **50** / 50 / 0 |

**読み方**
- 規則の向きは 4値モデル（2.3.3）と同じです。
- ファジィで新しく見えるもの：
  - **重すぎるのに足りない**（S1 土下座）。4値の先勝ちでは「足りない」に吸収されていました。
  - **失礼かつ足りない**（S2 バツが悪そう）。4値では「失礼」だけでした。
  - **半々**（S5 修正だけ：足りない 50・釣り合う 50）。4値では「足りない 27%」のように人の割合でしか表せませんでした。
- 平均所属度と裾は別のことを表します。現実のタスクの「てへっ」（S3）は、平均所属度が 55 で、失礼と感じる人が 100% です。この減点は受け手の性質にほとんど左右されないので、全員が「やや失礼」の少し上に並び、0.5 で切る割合が跳ねます。物語の中の「へらっと笑う」（S1）は、平均所属度が 50 でも、失礼と感じる人は 26% です。裾だけを見ると程度の情報が消えるので、主には平均所属度を見ます。
- 失礼の所属度関数の中心は、最初に置いた 1.5 では作例のどの回答でも失礼と感じる人が 0% になったため、1.2 に下げました。1.2 は、単独で最大級の失点（相手への指摘 1.2）で所属度が 0.5 になる位置です（P4）。旧版で失礼の判定に効いていた不足量を、失点から切り離した影響です。作例を見た後の調整です。

以下は、ファジィ化する前のモデルの結果です。2.3.1 はヒステリシスなし（v0.5 までの既定）、2.3.2 の「あり＋格上げ」は v0.6・v0.7 の既定です。

#### 2.3.1 ベンチマーク（ヒステリシスなし、受け手1000名、seed 7）

| 指標 | シミュレータ | 筆者 | ペルソナ多数決 |
|---|---|---|---|

| 一般的な謝罪指示 | 64.9% | 68.8%（44/64） | 78.1% |
| SHAZAI Rules | 72.1% | 75.0%（48/64） | 73.4% |
| 筆者との一致度 κ（192件） | 0.28（122/192 一致） | — | 0.06（108/192） |
| 検証用シナリオでの κ（3分割、seed 7/11/23） | 0.28 / 0.33 / 0.31 | — | 0.22 / −0.02 / 0.14 |
| 筆者の評定が母集団で10%未満の回答 | 32件 | — | — |

「失礼と感じる人の割合」：指示なし 29.1%、一般的な謝罪指示 11.5%、SHAZAI Rules 8.6%。
量の軸（平均）：不足は指示なし 0.71、一般的な謝罪指示 0.25、SHAZAI Rules 0.36。過剰はそれぞれ 0.03、0.05、0.03。

**読み方**
- 条件の順位は筆者と一致し、ペルソナは逆でした。
- 筆者に当てはめたθは、探索の乱数で大きく変わります。今のデータでは筆者の性質を特定しきれません。3回で一貫していたのは、最も遠い型が効率・道具型だったことです。

#### 2.3.2 ヒステリシス

| 条件 | κ | 想定外の回答 | 修復期の知覚（L0/L1/L2/L3） | 検証用シナリオでの κ | 当てはめた memory |
|---|---|---|---|---|---|
| なし | 0.28 | 32 | 41/49/9/0% | 0.28 / 0.33 / 0.31 | — |
| あり | 0.30 | 26 | 31/47/18/4% | 0.28 / 0.35 / 0.25 | 0.59 / 0.20 / 0.25 |
| あり＋格上げ（v0.6 の既定） | 0.31 | 28 | 31/47/18/4% | 0.28 / 0.35 / 0.24 | 0.59 / 0.20 / 0.21 |

- 修復期の知覚：ありでは、傷が残ることで修復期にも不満が深く読まれます（L2 以上が 9% から 22% に）。
- 修復期の評定：なしではどの条件も約9割が「釣り合う」で差が出ません。ありでは、指示なし 72%、一般的な謝罪指示 67%、SHAZAI Rules 82% となり、筆者と同じ順位（筆者は 6/8、5/8、8/8）になります。
- SHAZAI Rules の段階4の「釣り合う」：なし 87%、あり 71%、格上げ 76%（筆者 88%）。謝罪の目減りをそのまま入れると、深い謝罪まで割り引いてしまいます。格上げ（escalation）はこれを和らげます。
- κ の差は乱数による揺れ（約±0.05）の範囲内です。当てはめた memory は型の平均より低めにばらつき、今のデータでは傷の効果を識別できていません。各場面の経緯が1通りしかないため、経緯の効果を場面の違いと区別できないことが主な理由と考えています。

## 3. 既知の限界

1. 型の比率と性質の強さは事前値で、日本社会の分布を測ったものではありません。
2. ベンチマークの観察は代理で、一文ごとの読みとシグナルを含みません。`partisanship` と `embodiment` は、ベンチマーク上では効いていません。
3. 観察の規則と定数の一部は、検証データを見ながら調整しました。一致度は甘めに出ています。
4. 作例の結果は規則の向きの確認であり、人間の評定で検証したものではありません。
5. ショックの表出の規則（E-10）は仮説です。
6. 所属度関数の中心となだらかさ、「釣り合う」の t ノルム（min）は事前値です。失礼の中心は作例を見て調整しました（2.1）。
7. LLM の観察を通すとシミュレータが厳しすぎます。v0.9 では所属度関数の中心を出どころごとに較正して補っていますが、較正は筆者1名の評定によります。
8. 失敗の前の構え・修復期の控え・但し書きの係数と、傷が20ターンで消えるという仮定は事前値で、人間のデータで確かめていません。既存のベンチマークの観察には、これらの欄がありません。

## 4. 次に行う検証

0. `blind.py` で人間のブラインド評定（4つの述語×5段階）を集め、シミュレータとの差を測る（手順は [HUMAN_EVAL.md](HUMAN_EVAL.md)）。作例の組（23問）と、ベンチマークから抜いた40問程度から始める。あわせて、「釣り合う」の t ノルム（min か積か）と、所属度関数の中心・なだらかさを人間の評定から推定する。
0. v0.9 の人間の評価キット（[IMPROVEMENT_V09.md](IMPROVEMENT_V09.md) 8章）を実装し、仮説 H1〜H9 を事前登録して評定を集める。
0. 新しい観察の欄（失敗の前の構え・修復期の控え・但し書き）を含めて、観察者の集団（6変種）でベンチマークを観察し直す。
1. `observe` で層Aを独立に観察し、同じ検証をやり直す。
2. 20〜30人程度の評定で、型の比率と幅を推定する。筆者を含む各評定者が母集団に収まるかを見て、収まらなければ軸を足す。
3. 経緯だけを変えた場面の組（初回／3回目／虚偽を含む／約束を破った後、悪化の途中か回復の途中か）を作り、ヒステリシスを識別する。
4. 作例の組に人間の評定を付け、シグナルの規則の向きと大きさを確かめる。
