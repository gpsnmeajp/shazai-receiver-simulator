# 設計思想と目的

このシミュレータの設計の「なぜ」をまとめた文書です。今後設計を変えるときは、まずこの文書の原則と決定記録に照らしてください。仕組みの詳細は [ARCHITECTURE.md](ARCHITECTURE.md)、根拠となる研究は [EVIDENCE.md](EVIDENCE.md)、検証結果と変更履歴は [VALIDATION.md](VALIDATION.md) にあります。

## 1. 目的

**誠実に見える謝罪のかたち、つまり受け手に「釣り合っている」と感じさせる振る舞いとは何か**を、受け手の多様さを含めて測ることです。

- 出発点は、SHAZAI Rules（AIの謝罪を日本の文化に合わせる指示）のベンチマークです。そこでは、LLMペルソナによる評定が筆者の評定と大きくずれていました。
- 本シミュレータでは、「誠実に見えること」と「釣り合っていると感じること」を実質的に等価なものとして扱います（所有者の判断）。ただし研究上は両者が分かれる場面があります（[EVIDENCE.md](EVIDENCE.md) E-01）。分かれる場面では、主の出力は「釣り合い」とし、必要に応じて誠実さを副指標として出します。
- 対象は、AIアシスタントの現実のタスクでの謝罪、AIキャラクターの謝罪、物語の登場人物の謝罪です。

### 範囲

- **外から見える振る舞いだけ**を扱います。内面描写や、地の文による評価（「心から反省していた」など）は使いません。
- **観測時点（その謝罪の場面）までの経緯**を使います。その後の場面で約束が守られたかどうかは、その時点の評価には入れません（後の場面を評価するときに、経緯として入ります）。

## 2. 設計原則

**P1 観察と評価を分ける。** LLMには、回答に何が書かれ、何が描写されているかを記録させるだけにします（層A）。どう受け取るかは、コードで書いた受け手モデルが計算します（層B）。LLMの寛容さ、長い回答を好む癖、書き手の善意を前提に読む癖を、評価の段階から締め出すためです。

**P2 一つの判定ではなく、反応の分布を出す。** 受け手の母集団を性質の分布として持ち、回答ごとに「失礼／足りない／釣り合う／重すぎる」の割合を出します。謝罪は一番怒っている人に通用するかで決まるので、平均だけでなく「失礼と感じる人の割合」（裾）を重視します。

**P3 受け手は属性ではなく態度の軸で作る。** 年代や性別のペルソナをLLMに演じさせると、集団の姿を取り違え、平板にします（EVIDENCE A-01）。そこで、研究で効く向きが示された性質（察しの感度、当事者として読む度合い、修復の重視、重さへの耐性など）で受け手を表します。特定の評定者（筆者を含む）は「正解」ではなく、母集団の中の一点として扱います。

**P4 減点は足し合わせ、一つの失敗で崩れうるようにする。** 謝罪の評価は平均点ではなく、一番悪い一文や一つの振る舞いで崩れます。失点を合計して閾値で判定するので、一つの大きな失点だけで「失礼」になりえます。

**P5 不足と過剰を別々の軸で持つ。** 謝罪の中身の不足（必要な中身との差）と、重さの過剰（許容を超えた重さ）は別の現象です。どちらも連続値として出力します。

**P6 経緯で受け取り方が変わる（ヒステリシス）。** 信頼は損なわれやすく戻りにくいので、同じ回答でも、そこに至る経緯で受け取られ方が変わります。経緯は観測時点までの場面から読みます。

**P7 シグナルの信用度は場面の枠組みで決まる。** 同じ「しょんぼり」でも、物語の中の登場人物（またはAIキャラクター）の身体として描かれれば本物の合図として読まれます。一方、現実のタスクで失敗したAIのト書きや顔文字は、本物の代償を伴わない仮想の身体なので、受け取り方が人によって大きく分かれ、失敗が深刻なほど効きが落ちます。代償も同様で、物語の中では作中の代償が本物として働きますが、現実のタスクでは現実の代償（実際の作業、点検、返金など）しか代償として数えません。

**P8 シグナルの意味は文脈で反転しうる。** 照れや気まずさの表出は、過失が明白なら相手をなだめますが、曖昧なら後ろめたさの自白として読まれます。謝罪中の笑みは不誠実の信号ですが、物語の中の軽い失敗では愛嬌として受け取る人もいます。

**P9 すべての規則を根拠に対応づける。** 規則ごとに、根拠となる研究や事例を [EVIDENCE.md](EVIDENCE.md) に記録し、確度（強・中・仮説）を付けます。数値の大きさは多くが事前値で、人間のデータで推定していないことを明示します。

**P10 互換性を保つ。** 新しい欄は、既定値では従来と同じ結果になるようにします。後から足した受け手の性質は別の乱数列で引き、既存の検証結果を変えないようにします。

## 4. 未解決の問い

- 型の比率と性質の強さは事前値です。20〜30人程度の評定で、型の混合を推定する必要があります。
- ショックの表出の効果は、直接の研究を確認できていません（仮説）。
- 経緯の効果は、経緯だけを変えた場面の組がないと識別できません（[VALIDATION.md](VALIDATION.md)）。
- 「誠実に見えるか」と「釣り合うか」が分かれる場面で、どちらを主にするかは用途によって変わりえます。
- 物語の読者（第三者の視点）と、ゲームのプレイヤー（謝られた本人の視点）では、受け手の母集団そのものが違う可能性があります。
