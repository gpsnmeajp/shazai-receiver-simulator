# 事前登録：v0.9 の人間の評価（日本の受け手）

固定日：2026-11-19。データを集める前に固定します。変更した場合は、末尾の変更履歴に日付と理由を残します。
設計の背景は [IMPROVEMENT_V09.md](../docs/md/IMPROVEMENT_V09.md) 8章、機械で読める定義は [hypotheses-v09.json](hypotheses-v09.json) です。

## 1. 目的

受け手シミュレータ v0.9 の「控えの時間軸」（失敗の前の構え、謝罪の場面の構え、修復期の控え、免責の但し書きの局面）が、日本の受け手の受け取り方の向きと大きさを再現するかを確かめる。あわせて、シミュレータの予測分布を真に適正なスコアリング規則で採点する。

## 2. 材料

- 項目：`examples/scenes-v09.json` のうち `design.kit` が真の場面（`tools/make_scenes_v09.py` が生成）。4領域（コード修正・予定の操作・事実の回答・ファイルの操作）× 組 A（失敗の前の構え 5水準 × 謝罪 6種）・組 B（修復期の回答 5種 × 関係 2 × 傷の深さ 2）・組 C（但し書き 2種 × 局面 4）と、錨（組 D）4問。
- 問題束：`python3 blind.py pack --design --scenes examples/scenes-v09.json --repeat 2`。
- 割り付け：土台（組 A は領域ごと、組 B は領域×関係×傷の深さ、組 C は領域×但し書きの種類。計28）ごとに、一人の評定者は一つの水準だけを見る。リスト（30）は評定者IDのハッシュで決まる。錨は全員、注意の確認1問、再評定2問。1人あたり35問（約35分）。

## 3. 測度

| 測度 | 設問 | 値 |
|---|---|---|
| 失礼・足りない・重すぎる・釣り合う | 4つの述語×5段階（全項目） | 0, 0.25, 0.5, 0.75, 1 |
| 信頼意図 | 「このAIに、この先も任せられそうだと感じますか」（全項目） | 1〜5 → (x−1)/4 |
| 反省の知覚・再発の危険 | 修復期の項目 | 1〜5 → (x−1)/4 |
| 操作の確認 | 「失敗の前、AIはどのくらい自信を持って言っていましたか」（組 A・C。主の設問の後） | 0〜3 |
| 注意の確認 | 4つすべて「ある程度」を選ぶ指示 | 通過・不通過 |

## 4. 仮説と検定

仮説は H1〜H8（24の対比。うち H3c は探索）と H9（t ノルム）。各対比は、セル（`design` の値で絞った項目）の平均の重み付き和で、領域をまたいで平均する。一覧は [hypotheses-v09.json](hypotheses-v09.json)。

- 検定：評定者を単位にしたブートストラップ（2,000回）の標準誤差による正規近似。片側（`two-sided` は両側）。
- 多重比較：primary の23対比に Holm 法。α = 0.05。
- 支持の基準：調整後の p < 0.05 かつ |推定値| ≥ 0.10（所属度または 0〜1 にした尺度の差）。
- H9：評定者が直接答えた「釣り合う」と、同じ評定者の三つの答えから作った min と積の、平均絶対差を比べる（`blind.py compare` の人間どうしの節）。
- シミュレータとの突き合わせ：同じ対比をシミュレータの項目ごとの予測（平均所属度、信頼意図は `reliability`）で計算し、向きの一致を報告する。シミュレータの係数はデータを見て変えない。

## 5. 主指標（シミュレータの採点）

述語ごとの5段階の順位確率スコア（RPS）。予測分布は、受け手一人ずつの所属度に評定者のノイズ（σ = 0.1）を足して5段階に丸めたもの。基準は一様分布と人間の評定の周辺分布。`python3 blind.py compare ... --rps`。

## 6. 人数と止め方

評定者 40〜60 名（合成評定者による検出力の見積もりは `eval/v09-kit/power-*.md`）。60 名に達したら止める。途中で結果を見て人数を変えない。

## 7. 除外と感度分析

- 主分析では除外しない。
- 感度分析：注意の確認に通らなかった評定者を除いた結果（`--exclude-inattentive`）、操作の確認で構えが伝わらなかった評定（組 A で、断言の水準なのに 0〜1 と答えたものなど）を除いた結果。
- 所要時間が1問あたり10秒未満の評定者は報告する（除外しない）。

## 8. 実行のコマンド

```text
python3 blind.py pack --design --scenes examples/scenes-v09.json --repeat 2 --out-dir human/kit-v09
python3 sim.py scenes examples/scenes-v09.json -o out/scenes-v09.json
python3 blind.py compare --key human/kit-v09/key.json --ratings "human/kit-v09/ratings/*.json" \
  --sim out/scenes-v09.json --scenes examples/scenes-v09.json --hypotheses human/hypotheses-v09.json --rps \
  --group-by set,domain -o human/kit-v09/compare
```
